# ZEUS SELF — Starter

نسخه شروع پروژه ZEUS SELF برای اجرای ربات مرکزی روی Railway.

## امکانات فعلی
- نمایش پلن‌های ۱ تا ۱۲ ماهه
- دریافت رسید کارت‌به‌کارت به‌صورت عکس
- ارسال رسید برای مدیر
- تأیید یا رد دستی پرداخت
- فعال‌سازی و تمدید اشتراک پس از تأیید مدیر
- مشاهده وضعیت اشتراک
- تنظیم قیمت هر پلن با دستور `/setprice`

## محدوده این نسخه
این ZIP یک **نسخه اولیه مدیریت اشتراک** است؛ هنوز وارد حساب شخصی کاربران نمی‌شود و ارسال خودکار پیام از حساب کاربران را انجام نمی‌دهد. دریافت رمز، کد ورود یا نشست خام کاربران در یک ربات مرکزی ریسک امنیتی بالایی دارد. برای قابلیت انتشار پیام، مسیر امن‌تر این است که ربات فقط در گروه‌هایی کار کند که مدیران آن صریحاً اجازه داده‌اند و پیام‌ها برای اعضای موافق/مخاطبان opt-in باشند. از ارسال انبوه ناخواسته یا دور زدن محدودیت‌های تلگرام استفاده نکنید.

## اجرای محلی
1. Python 3.11+ نصب کنید.
2. وابستگی‌ها را نصب کنید:
   `pip install -r requirements.txt`
3. `.env.example` را به `.env` کپی و مقادیر را تکمیل کنید.
4. اجرا:
   `python -m app.main`

## متغیرهای Railway
این موارد را در Variables قرار دهید:
- `BOT_TOKEN`: توکن BotFather
- `ADMIN_ID`: شناسه عددی مدیر (در این نسخه روی `9158813748` پیش‌فرض شده؛ در صورت نیاز در Railway قابل تغییر است)
- `CARD_NUMBER`: شماره کارت
- `CARD_OWNER`: نام صاحب کارت
- `DATABASE_PATH`: برای تست؛ مقدار پیش‌فرض `zeus_self.db`

## مهم درباره دیتابیس Railway
فایل SQLite ممکن است با جابه‌جایی/حذف کانتینر پایدار نماند. برای استفاده واقعی، PostgreSQL را به پروژه Railway اضافه کنید و لایه دیتابیس را به PostgreSQL منتقل کنید یا یک Volume پایدار متصل کنید. قبل از فروش عمومی، بکاپ‌گیری، لاگ‌گیری امن، محدودسازی دسترسی مدیر و تست پرداخت را اضافه کنید.

## دستورات
- `/start`
- `/plans`
- `/status`
- `/admin` (فقط مدیر)
- `/setprice 1 150000` (فقط مدیر؛ مثال قیمت)

قیمت همه پلن‌ها در شروع صفر است و مدیر باید آن‌ها را جداگانه تنظیم کند.
